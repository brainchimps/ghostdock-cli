# ghostdock CLI releases

Release files of the `ghostdock` CLI: archives for macOS, Linux and Windows, `checksums.txt` with its signature, release notes, and `install.sh`. The source is private; every file here is published by the release workflow of the Ghostdock platform.

## Install

```bash
brew install brainchimps/tap/ghostdock
```

```bash
curl -fsSL https://ghostdock.brainchimps.com/install.sh | sh
```

```bash
npm install -g ghostdock
```
